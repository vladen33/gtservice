# Для Python
- Python (от Microsoft) — база: автодополнение, отладка, линтинг, работа с виртуальными окружениями и Jupyter. 
- Pylance — языковой сервер, который работает в связке с Python. Даёт продвинутую проверку типов, умные автоимпорты и улучшенное автодополнение. 
- Ruff — быстрый линтер и форматтер. Он не только подсвечивает проблемы, но и может автоматически их исправлять (например, сортировать импорты или удалять неиспользуемые переменные). Работает быстрее многих аналогов. 
- autoDocstring — автоматически генерирует docstrings для функций и классов, когда вы набираете три кавычки. Экономит время и поддерживает популярные стандарты (Google, NumPy). 

# Для Django
- Django Structure Explorer — то, что ты искал в прошлый раз! Он строит дерево проекта, автоматически находит приложения, модели, представления, URL-паттерны. Можно прямо из панели переходить к определениям, смотреть поля моделей и детали URL. 
- Django (официальное расширение) — добавляет подсветку синтаксиса для шаблонов, сниппеты и команды для запуска management-команд (например, runserver) прямо из VS Code. 
- Djlint — линтер для HTML-шаблонов Django. Помогает ловить ошибки в синтаксисе шаблонов и невалидную разметку. 

# Для фронтенда (HTML, CSS, JavaScript)
- Live Server — при сохранении файла автоматически обновляет страницу в браузере. Огромная экономия времени при верстке и отладке фронтенда. 
- Auto Rename Tag — автоматически переименовывает парные теги в HTML: меняешь открывающий — меняется и закрывающий. 
- CSS Peek — позволяет быстро смотреть CSS-правила: наведи курсор на класс в HTML — увидишь стили во всплывающем окне, а с зажатым Ctrl перейдёшь к определению в CSS-файле. 
- IntelliSense for CSS class names in HTML — расширяет автодополнение: при вводе атрибута class редактор предлагает варианты из всех CSS-файлов проекта. 
- JavaScript (ES6) Code Snippets — готовые шаблоны кода для современного JavaScript. Вводишь сокращение — получаешь конструкцию. 
- ESLint — статический анализатор для JavaScript/TypeScript. Подсвечивает проблемные места и часто предлагает автоисправления. 

# Общие и вспомогательные
- GitLens — расширяет встроенные возможности Git: показывает аннотации (кто и когда изменил строку), историю изменений, визуализацию веток. 
- vscode-icons — заменяет стандартные иконки файлов и папок на более узнаваемые для разных языков и типов файлов (Python, JS, CSS и т.д.) — так в проводнике проще ориентироваться. 
- Error Lens — выводит текст ошибки прямо рядом со строкой кода, где она возникла. Это сильно снижает когнитивную нагрузку при отладке. 
- Prettier — универсальный форматтер. Настраивается так, чтобы при сохранении файла автоматически приводить к единому стилю код на Python, JavaScript, HTML, CSS.
